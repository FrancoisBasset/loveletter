Ce projet est une **adaptation indépendante et non officielle**, sans affiliation ni approbation annoncée de Z-Man Games, Asmodee ou des auteurs du jeu. Le nom Love Letter sert à identifier le jeu dont les mécanismes sont étudiés et implémentés. Les marques et créations de leurs titulaires restent leur propriété.

Crédits de la référence : conception originale de **Seiji Kanai** ; nouvelle édition Z-Man Games 2019 développée par **Justin Kemppainen et Alexandar Ortloff** ; illustrations de l'édition physique par **Andrew Bosley**, non utilisées dans ce projet. Ces crédits décrivent le jeu de référence et ne signifient pas une contribution de ces personnes au code ou aux dessins de l'application.

## Ce qui est inclus

Le dépôt fournit du code Kotlin original, des dessins géométriques et mises en page originaux, ainsi que des explications françaises rédigées pour cette application. Il ne contient pas les illustrations officielles, le logo, les faces de cartes, les aides imprimées ni les PDF de règles de l'éditeur. Le moteur utilise les noms français des catégories de cartes et leurs mécanismes, avec une documentation des sources dans `rules.md`.
